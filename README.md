# StudySync 📚

A modern student study planner and productivity web application built with React.

## 🚀 Live Demo

[View Live Demo](https://study-sync-murex.vercel.app/)

## 📂 GitHub Repository

[View Source Code](https://github.com/aishamohiuddin-source/StudySync)

## ✨ Features

- 📊 Interactive Dashboard
- 📚 Study Planner
- ⏱️ Pomodoro Timer
- ✅ Task Manager
- 📅 Study Calendar
- 📈 Study Statistics
- 💾 Local Storage data persistence
- 📱 Responsive user interface

## 🛠️ Tech Stack

- React.js
- Vite
- React Router
- JavaScript
- HTML5
- CSS3
- Local Storage
- Git & GitHub
- Vercel

## 🎯 Purpose

StudySync was created to help students organize study sessions,
manage daily tasks, track productivity, and maintain consistent
learning habits.
